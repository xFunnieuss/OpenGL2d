# Bouncy Ball Simulation

I wanted to mess around with physics in OpenGL, so I wrote a basic bouncy ball app.
The aim was to implement realistic physics to accurately simulate bouncy balls in a tank

There are a few ways to interact with the ball:

Spawn one with left click, or spawn a moving one with G
You can resize the window to give the balls more space, or move the window around to shake them up!

You can also spawn in blocks using X to make obstacles for the balls (WIP)

Written on Linux, untested on other devices but probably fairly simple to get working.
